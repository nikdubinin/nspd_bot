
# Документация по коду NSPD Telegram Bot

## Общая архитектура

Проект состоит из одного основного модуля `bot.py`, который реализует:

- настройку логирования;
- загрузку конфигурации (токен бота) из `.env`;
- инициализацию клиента НСПД (`nspd_request.NSPD`);[web:12]
- асинхронные обработчики Telegram‑бота (`python-telegram-bot`);
- функцию форматирования ответа из НСПД в человекочитаемый вид.

### Основные зависимости

- [`python-telegram-bot`](https://docs.python-telegram-bot.org/) — асинхронный Telegram‑бот.[web:10]
- [`nspd-request`](https://pypi.org/project/nspd-request/) — упрощённый доступ к открытому API НСПД.[web:12]
- `python-dotenv` — загрузка переменных окружения из `.env`.

## Поток обработки запроса

1. Пользователь отправляет боту текстовое сообщение.
2. Обработчик `kad_number_handler`:
   - игнорирует команды (`/start`, `/help` и т.п.);
   - вызывает `normalize_kad_number`, чтобы привести ввод к стандартному формату;
   - если формат некорректен — отвечает вежливым сообщением и просит проверить номер;
   - если формат валиден — отправляет промежуточный ответ и делает запрос в НСПД.

3. Для доступа к НСПД используется метод `nspd_api.get_info(kad_number, include_geom_id=True, include_object_type=True)`. Он возвращает словарь с полными данными объекта; библиотека описывает этот метод как универсальный, возвращающий все основные данные по кадастровому номеру.[web:12]

4. Результат передаётся в `format_object_info`, которая:
   - извлекает ключевые поля: кадастровый номер, тип, площадь, адрес;
   - формирует блок о правах (список, если есть данные);
   - формирует блок об ограничениях и обременениях;
   - собирает человекочитаемое сообщение и возвращает строку.

5. Ответ отправляется пользователю в Telegram.

## Описание ключевых функций

### `normalize_kad_number(raw: str) -> str | None`

Назначение: попытаться привести строку к формату кадастрового номера `NN:NN:NNNNNNN:NNN`.

- Удаляет все символы, кроме цифр и двоеточий.
- Если двоеточий нет, пробует вставить их по шаблону `2-2-остальное-3`.
- Проверяет результат регулярным выражением:
  - 2 цифры;
  - двоеточие;
  - 2 цифры;
  - двоеточие;
  - 1–7 цифр;
  - двоеточие;
  - 1–7 цифр.
- Возвращает нормализованный номер или `None`, если формат не распознан.

### `format_object_info(data: dict) -> str`

Назначение: преобразовать словарь с данными НСПД в текст для Telegram.

Основные шаги:

- Безопасно извлекает вложенные поля (`attrs.cadNumber`, `attrs.areaValue`, `attrs.address` и т.д.).
- Формирует заголовок и основные характеристики.
- Обходит массивы прав и ограничений (`rights`, `restrictions` или аналоги, если присутствуют).
- Возвращает готовый текст с маркированными списками.

Так как структура реального ответа НСПД может отличаться, при интеграции рекомендуется:
- временно логировать полный `data`;
- при необходимости адаптировать ключи полей под актуальную схему.

### Обработчики Telegram

- `start_handler` — приветствие и краткая инструкция.
- `help_handler` — подсказка по форматам ввода и использованию.
- `kad_number_handler` — основной бизнес‑обработчик кадастрового номера.
- `error_handler` — глобальный ловец исключений во время обработки апдейтов.

## Конфигурация и безопасность

- Токен бота хранится только в переменной окружения `TELEGRAM_BOT_TOKEN`.
- Для разработки используется `.env`, который не следует коммитить в репозиторий.
- В `config.example.env` дан пример структуры `.env` без реальных секретов.

## Возможные доработки

- Более строгая валидация кадастрового номера (по регионам, длинам блоков и т.п.).
- Разделение на модули: `handlers.py`, `services/nspd_service.py`, `utils/validators.py`.
- Локализация сообщений (например, поддержка английского языка).
- Добавление кэширования запросов НСПД, если начнётся активное использование.
