# NSPD Cadastral Bot

Telegram-бот: по кадастровому номеру запрашивает сведения в НСПД (Национальная система пространственных данных) и присылает карточку объекта, а также готовит тексты предложений для инвесторов.

## Возможности

- Распознаёт номер в любом виде: `77:03:0002007:7190`, `77 03 0002007 7190`, `77030002007 7190`, `770300020077190`.
- Поддерживает земельные участки, здания, сооружения, ОНС, помещения (квартиры) и машино-места.
- Карточка объекта: тип, адрес, площадь, категория земель, ВРИ, назначение, этаж/этажность, материал стен, годы постройки/ввода, статус, форма собственности, вид права, кадастровая стоимость с датами.
- Кнопки под карточкой:
  - **НСПД** и **Яндекс.Карты**: объект на карте;
  - **Связанные объекты**: здания на участке и участки под зданием; для помещения кнопка **Здание**;
  - **Займ под залог**: бот спрашивает, один объект в залоге или несколько. Для нескольких пришлите кадастровые номера с новой строки, и бот соберёт одно предложение по всем объектам с суммарной кадастровой стоимостью;
  - **Срочный выкуп**: текст предложения для инвесторов;
- **Анкета вместо пустых граф.** Перед текстом предложения бот по очереди спрашивает:
  - для займа: сумму, срок, цель, место работы и должность, доход, наличие ИП / самозанятости / ООО, обременения и зарегистрированных лиц (если в залоге есть помещение);
  - для выкупа: цену, срок сделки, обременения и зарегистрированных лиц.

  Ответить можно текстом или кнопкой с готовым вариантом, вопрос можно пропустить (графа останется пустой) или вернуться назад. Кнопка «Остальное заполню сам» сразу выдаёт текст. Голые суммы оформляются автоматически: `4500000` превращается в `4 500 000 руб.`;
  - **Обновить**: свежие данные без кэша;
  - **JSON**: исходный ответ НСПД файлом.
- **Пакетный запрос**: несколько номеров в одном сообщении. Бот пришлёт сводку и CSV-таблицу для Excel.
- `/pledge` — залог нескольких объектов без открытия карточки, `/cancel` — отменить ввод номеров.
- `/history` — последние запросы. Режим `/short` и `/full` и история сохраняются после перезапуска.
- Доступ можно ограничить списком пользователей (`ALLOWED_USERS`).

> Сведения о правообладателях и обременениях НСПД в открытом доступе не публикует. Для них нужна выписка из ЕГРН.

## Установка и запуск (Windows)

1. Скопируйте `config.example.env` в `.env` и укажите `TELEGRAM_BOT_TOKEN`.
2. Запустите `start_bot.bat` или ярлык **NSPD Bot** на рабочем столе.
   Скрипт сам создаст `venv`, установит зависимости и перезапустит бот, если тот упадёт.

Вручную:

```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python bot.py
```

## Запуск в Docker Desktop

Бот берёт токен и настройки из того же `.env`. Состояние чатов (`data/`) и подробный журнал (`logs/`) хранятся в папке проекта и не пропадают при пересборке.

> Одновременно может работать только один экземпляр бота. Перед запуском в Docker закройте окно `start_bot.bat`, иначе Telegram будет отдавать сообщения то одному, то другому.

Первый запуск и запуск после изменений в коде:

```bash
docker compose up -d --build
```

Дальше бот управляется из Docker Desktop: вкладка **Containers**, контейнер `nspd-bot`, кнопки Start / Stop / Restart. Благодаря `restart: unless-stopped` бот сам поднимается после падения и при запуске Docker Desktop.

**Журнал действий никуда не пропадает:**
- **Docker Desktop:** Containers → `nspd-bot` → вкладка **Logs**. Там те же строки, что в консоли батника, в реальном времени и с поиском.
- **Терминал:**

  ```bash
  docker compose logs -f --tail 100
  ```

- **Файл** `logs/bot.log` в папке проекта: полный журнал с трассировками ошибок.

Время в журнале московское (`TZ=Europe/Moscow` в образе). При остановке контейнера бот успевает напечатать строку `ОСТАНОВКА` с итогами.

Тесты внутри образа:

```bash
docker compose run --rm nspd-bot python -m unittest discover -s tests -t .
```

## Настройки (.env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен от @BotFather (обязательно) |
| `ALLOWED_USERS` | пусто (все) | Telegram ID и/или @username через запятую |
| `TELEGRAM_PROXY` | — | прокси для Telegram |
| `NSPD_TIMEOUT` | 15 | таймаут запроса к НСПД, сек |
| `NSPD_RETRIES` | 3 | попыток при сбоях НСПД |
| `NSPD_CONCURRENCY` | 4 | одновременных запросов к НСПД |
| `CACHE_TTL_MINUTES` | 30 | время жизни кэша |
| `MAX_BATCH` | 20 | максимум номеров в одном сообщении |
| `LOG_LEVEL` | INFO | уровень логирования |

Состояние чатов хранится в `data/state.pickle`.

## Консоль и журнал

В окне консоли (при запуске через `start_bot.bat`) бот печатает по строке на каждое действие:

```
14:05:31  ЗАПУСК    бот @your_nspd_bot v2.0.0 запущен · 29.10.2026 · доступ открыт всем
14:06:02  НОВЫЙ     Иван (@ivan_broker) · id 101 · впервые с момента запуска
14:06:02  команда   Иван (@ivan_broker): /start
14:06:10  ЗАПРОС    Иван (@ivan_broker) → 77:01:0001001:1000 · Земельный участок · г. Москва, Тверской, ул. Манежная, з/у 2А · 2,0 с
14:07:15  ЗАЛОГ     Ольга (id 202): займ под залог · 77:03:0002007:12000, 77:03:0002007:12500 · в предложении 2 из 2 · 2,5 с
15:05:31  СВОДКА    работаю 1 ч 0 мин · пользователей 2 · запросов 5 (найдено 4, не найдено 1, сбоев 0) · пакетов 1 · предложений 2 · ошибок 0
```

Метки: `ЗАПУСК`, `НОВЫЙ` (пользователь впервые с момента запуска), `команда`, `ЗАПРОС`, `ПАКЕТ`, `ПРЕДЛОЖ`, `ЗАЛОГ`, `кнопка`, `текст` (номер не распознан), `ДОСТУП`, `СБОЙ` (НСПД не ответила), `ВНИМАНИЕ`, `ОШИБКА`. Раз в час выводится `СВОДКА`, при остановке — `ОСТАНОВКА` с итогами.

Подробный журнал со всеми деталями и трассировками ошибок пишется в `logs/bot.log`.
