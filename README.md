# NSPD Cadastral Bot

Телеграм‑бот, который по кадастровому номеру объекта недвижимости запрашивает сведения в НСПД (Национальная система пространственных данных) и выводит основные характеристики объекта.[web:12]

## Возможности

- Принимает кадастровый номер в свободном формате (с пробелами, без двоеточий).
- Нормализует номер к стандартному виду.
- Запрашивает данные об объекте через библиотеку `nspd-request`.[web:12]
- Выводит:
  - кадастровый номер;
  - тип объекта (ЗУ/ОКС, и др.);
  - площадь и адрес (если доступны);
  - кадастровую стоимость и другие характеристики (если доступны).

> Важно: открытый НСПД‑геопортал не предоставляет детализированные сведения о зарегистрированных правах и обременениях.
> Для официальных данных требуется выписка ЕГРН.

## Требования

- Python 3.12+
- Аккаунт Telegram и созданный бот (через @BotFather).

## Установка

```bash
git clone <ваш-репозиторий> nspd_bot
cd nspd_bot

python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

Создайте файл `.env` на основе `config.example.env` и укажите токен:

```env
TELEGRAM_BOT_TOKEN=...
```

## Запуск

```bash
python bot.py
```

## Команды бота

- `/start` — приветствие
- `/help` — справка
- `/short` — краткий формат ответа
- `/full` — подробный формат ответа

## Кнопки под ответом

- **Открыть в НСПД** — открыть объект на карте НСПД
- **Показать связанные объекты** — показать связанные кадастровые номера (если доступны)
- **Показать raw JSON** — сырые данные НСПД (для отладки)
